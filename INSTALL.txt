TERM AT TARGET 3.0.2 — SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/TermAtTarget

Download Term-At-Target.jxa and SHA256SUMS from the same release. To build
from source, see CONTRIBUTING.md in the source repository.

Verifying what you downloaded
=============================

The attached release files have GitHub build attestations. With the GitHub
CLI installed, verify the script and its SHA-256 checksum from the folder
where you saved the files:

    gh attestation verify "Term-At-Target.jxa" \
        --repo resoltico/TermAtTarget
    shasum --check SHA256SUMS

Requirements
============

The script targets macOS 12.3 or later and uses the Shortcuts and Terminal
apps supplied with macOS. The release's native-macos.json identifies the
macOS build, architecture and checks used to qualify the attached script.

Install the Quick Action
========================

1. Open Shortcuts and create a new shortcut named Term At Target.
2. In Details, enable Use as Quick Action and Finder.
3. Configure the shortcut to receive Files and Folders from Finder. Set
   If there's no input to Continue so a run without input shows the start menu.
4. Add Run JavaScript for Mac Automation. Do not use Run AppleScript or the
   similarly named JavaScript-on-Web-Page action.
5. Delete the example code. Paste all of Term-At-Target.jxa into the action.
6. Set the input to Shortcut Input. Leave this as the only action. Querying
   Finder from inside the shortcut can bypass the start prompt. Copying or
   converting the input can change its path or resolve an alias.
7. Control-click one item in Finder and choose Quick Actions > Term At Target.
   If it is missing, look for the shortcut in the Finder extensions settings.
   To run with keys, use Add Keyboard Shortcut in the shortcut's Details.
8. Test a regular file, a folder and a Finder alias whose location differs
   from its target. In the opened shell, use pwd -P to check the destination.
   Run from the Shortcuts app without input to check the start prompt.

Grant access to the selected location when macOS or Shortcuts asks.

Settings
========

Run the shortcut without input and choose Settings…. Choose a setting
and value, then choose Use to save it or Back to return without saving.
Choose Done to close Settings. Available settings:

    Terminal app:                       Terminal / Ghostty / iTerm2 / kitty
    When a folder is selected:          Ask each time / Open inside /
                                        Open in parent
    When a Finder alias is selected:    Ask each time / Follow the alias /
                                        Open where it is

The defaults are Terminal and Ask each time for folders and Finder aliases.
Ghostty, iTerm2 and kitty are offered when macOS can find them. Download them
from their vendors. If macOS cannot find an app you just installed, open it
once from Applications and try again. Choose another terminal app for a
folder whose path contains "$", which kitty can expand as a variable.

Shortcuts can pass a symbolic link's target in place of the link, or drop an
unavailable input. The script applies its rules to the object it receives.

Settings live in the com.resoltico.TermAtTarget macOS preferences domain
and are independent of the script text.

Removal
=======

Disable and delete the shortcut and remove any assigned keyboard shortcut,
then remove the saved settings:

    defaults delete com.resoltico.TermAtTarget

The shortcut and its preferences are the only project data to remove.
